# Suggested direction — for discussion

## A coherent Founders experience

Use the task workspace's structure and the analytics screen's hierarchy as the main references. Study the SmartShort selection treatment for clarity while testing a quieter version against Founders. The repo's existing Founders skill favors hairlines, a restrained accent, Instrument Sans, tabular figures, and no glows; this batch is inspiration, not an automatic override.

Use one shared shell, spacing system, typography system, and component vocabulary. Component sites supply individual ideas; do not combine whole competing design systems. Screens should still feel like one Folio product.

## Motion with a job

Proposed applications of the owner's selected tools:

- Skullet: reserve the final layout during loading so cards and tables do not jump.
- Torph: show status or selected-value changes; test dense and rapidly updating numbers before adopting.
- Liveline: represent actual live activity, such as active agent runs or incoming campaign events. Label synthetic showcase feeds as demo data.
- visx: historical campaign trends, funnel comparisons, date ranges, and sources.
- React Flow: campaign strategy and automation relationships. Supply a readable list or step view for small screens and simpler interaction modes.
- Gauge UI: a focused target or budget indicator when it answers a specific question; bars and plain numbers may read faster elsewhere.
- mdxcn: structured knowledge articles and embedded diagrams, not the entire knowledge-management experience.

Keep public-site presentation motion distinct from daily app motion. The public site can tell a staged story; the app should make frequent actions quick and stable. Offer reduced-motion alternatives. Analog should also have simpler choices, explicit labels, larger controls and text, and calm updates—not merely a new palette.

## First showcase stories to consider

1. **Find a prospect.** Choose an area and business type → inspect results → qualify a candidate → add to Folio. Show the selected prospect entering the CRM.
2. **Launch a campaign.** Linked accounts → campaign brief → channel-specific previews → review → scheduled deployment → results. Use explicit demo states for publishing that is not implemented.
3. **Run Folio on the go.** Open the streamlined mobile view → capture a lead or note → review an item → open a relevant conversation. Choose only three to five primary shortcuts after workflow review; keep legacy view available.
4. **Give an agent useful knowledge.** Add a source → inspect retrieval/citations → review an answer → view the run. This connects knowledge base, agents, and human oversight into one story.

Suggested order for concept screens: marketing manager, mobile quick actions, prospecting, then sign-in and knowledge-base detail. This order is a recommendation, not an owner-approved priority.
